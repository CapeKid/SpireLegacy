# Spire Legacy 1.0.32

Standalone wording now covers the Workshop/Melty descriptions, installation guides, embedded design manifests and asset inventory. Original generation prompts and obsolete extraction/authoring implementations, old listing configurations and historical audit snapshots have been removed from the current tree. Published Git history remains intact.

Art directions describe the current illustrations; they are not verbatim generation records. AI artwork and private style-reference use remain disclosed, along with the MIT copyright and dependency notices. No artwork bytes, cards, trait effects, manor progression or saved model IDs change. Retired commands still refuse execution and imports. Package inspection reports use `standaloneAssets` (release validation) and `standalone_assets` (package build) instead of the obsolete dependency flag.

This change prepares versioned release metadata; it does not upload to Workshop or Melty or change item visibility.

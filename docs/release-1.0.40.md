# 1.0.40 — beta Second Quiver reload

Second Quiver now costs **1 Energy** and returns **up to 2 Attacks** from the discard pile to hand (**3 upgraded**), then **Exhausts**. It no longer draws cards or grants Energy. Meditate remains the shared, zero-cost immediate draw-and-Energy burst, unchanged in both forms.

The Ranger card now helps rebuild an Attack sequence for Hunter Rhythm instead of duplicating Meditate's resource burst. Its optional selection supports partial or empty discard piles. Skills and Powers are excluded; a Pacifist basic that has become a Skill is not an eligible Attack. Existing recovery-card exclusions remain respected. Native hand limits apply, and replaying the Skill uses the current discard pile for each resolution.

The selection is bound to the owner's run through CardChoiceLifetime, matching the other custom recovery effects. The card's saved ID, illustration, rarity and pool membership are unchanged. The upgrade increases only the recovery limit. Balance overrides and the audit preserve regeneration.

Delivered only to private beta Workshop item **3822395190** (`SpireLegacyBeta`). Public Workshop item **3816525393** remains on **1.0.39**. A PR targets GitHub main without merging it. Native checks use owned Windows copies; physical Steam Deck selection and full-climb balance remain playtesting tasks.

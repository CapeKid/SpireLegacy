# Ancient, reward and Architect dialogue audit (#56)

Baseline: merged main `cc998f3`. This audit found **no reproducible production gameplay defect in the covered flows**. It corrects and extends the private test fixtures; original conversations, reward rules, card amounts and live owner-selection patches are unchanged. [Validated evidence](adversarial-ancients-evidence.json) contains exact source/DLL hashes, seeds, inputs, measurements and complete deduplicated native diagnostics. Tests used independent owned-game Windows copies, disposable family/native profiles, regular **v0.107.1**, public-beta **v0.111.0**, BaseLib **3.4.7** and Spire Legacy **1.0.29**. Nothing was published or installed into personal game folders.

## Completed native coverage

- **672 Ancient selector cases per branch**: eight Ancients, three classes, visit counts -1/0/1/4/10/100/int.MaxValue, total visits 0/200 and both character-agnostic-dialogue flags. Each returns four correctly ordered, class-owned localized lines and response prompts. Native Ironclad dialogue and Ancient option catalogues remain unchanged.
- Future-Ancient fallback: six native selector cases per branch using a throwaway registered dialogue set and original fallback text. Unregistered/empty sets retain native empty behavior, and tagging the future set does not change native character behavior. This emulates getter registration; it does not introduce a fake game model or claim a future NPC reward implementation.
- **15 Architect selector cases per branch**, covering every class at 0/1/4/10/100 previous wins, first/return localization and original ending attacker flags.
- **48 rendered Ancient class/visit flows per branch**: every Ancient × every class × first/return. Mouse-style release callbacks and native accept-action events advance all four lines; the final reward control is visible, enabled and focusable. Real option-button dispatch selects a reward through native event synchronization, completes any intermediate reward screens, then saves/resumes the run. Repeating the same completed reward choice does not acquire another relic.
- Regular Scroll Boxes exposes a bundle-selection screen: choose, cancel the preview, choose again and confirm through native controls. Calling Bell's additional relics and Lost Coffer's reward screen are retained in the measured acquisition results rather than mistaken for duplicate rewards. Native reward screens are resolved through their card/reward/proceed callbacks.
- **Six actual Architect victory transitions per branch**: every class's first/return ending advances each line and executes final Proceed. The fixture places a disposable run in its final act and sets private native prior-win counters; this is an ending callback test, not a natural campaign victory. Each lineage settles once. A repeated completed-option invocation is idempotent on regular; beta rejects it after marking the event finished. The complete beta rejection is recorded, and neither branch settles the family again.
- **12 Dusty Tome acquisition/save cases per branch**: three classes × ordinary/Pacifist/Hero Complex/Super Healer. Sixty native Tome rolls per case see both class Ancient cards, never another class's card. Actual acquisition adds an upgraded card; native card serialization and full run save/resume preserve its identity and slot. Existing Tome/parity coverage from #54 remains applicable.
- Separate persistent Neow save boundaries cover every class's first/return visit. Tome acquisition is saved, loaded and inspected; dialogue saves before reward return to the correct class's initial line; completed rewards are saved with the native finished-room marker and are not offered again after loading. The broader debug-room matrix verifies callbacks; this persisted map-node fixture verifies event-save behavior.
- **12 baseline paid Ancient card forms per branch**: all six cards, base/upgraded. Kingbreaker, hand-only Arsenal upgrades, Conductor's first-Skill draw/charge cap and next-turn reset, Elixir healing, Canopy's next-turn Block and Escape's Buffer resolve. Conductor trigger Skills now use paid manual play rather than autoplay.
- **48 additional Ancient modifier cases per branch**, covering all cards/forms under those four trait sets. Save identity, resolution and table-node cleanup pass; Elixir heals 6 normally, 12 with Super Healer, and 0 with Hero Complex. Pacifist correctly refuses the non-basic Kingbreaker at both levels, spending no energy. The other cases use funded paid plays to isolate effects from opening energy limits.
- Knight/Mage, Knight/Ranger and Ironclad/Mage native two-peer parties on both branches: each peer initializes owner-bound Architect models and checks 24 Ancient selectors per owner. Both peers agree; remote heirs use their frozen class, native characters retain native keys, and the ambient eligibility-owner scope is restored. Native checksum checking remains enabled. These are model/selector ownership checks, not remote-rendered event or complete co-op victory claims.

## Fixture corrections and diagnostics

Old selector fixtures changed the menu heir while a live character already held a frozen class snapshot. They now enumerate from the menu or use the actual owner; the older Tome probe samples its real class rather than pretending to change that live class. Public-beta also requires an EventCombatSynchronizer argument when initializing combat-layout event models, so the ownership fixture supplies the native synchronizer through the supported signature.

Save fixtures also need native room semantics: a debug room swap does not replace its map-node identity, and `SaveRun(null)` deliberately omits a finished-room marker. The dedicated boundary fixture uses a persisted Ancient map node and passes the completed room to native saving. These are fixture corrections, rather than a patch to native gameplay/save behavior.

Early regular reward probes stalled because they did not operate the additional bundle/rewards screens. Those requests were not replayed; private timeout screenshots and diagnostics were retained, and subsequent probes used fresh profiles. Adding test energy did not bypass Pacifist: its restriction applies to non-basic Attacks, so that case verifies rejection. Dusty Tome can still offer that forbidden Ancient card; this is recorded as an existing trait/reward tradeoff, without changing progression or reward balance.

Native renderer/particle, WorkerThreadPool, missing-backup deletion and finished-event diagnostics are retained in the proof. They were not suppressed or described as production fixes. Resource investigation remains in #58; platform/install concerns remain in #62. Build passed with zero warnings/errors; core checks passed **164,053 assertions**, harness checks passed **20 checks**, and preflight validated **32 sheets / 2,062 rows / 26,477 cells**.

## Explicit deferrals

Physical Steam Deck/Linux input, non-English locale switching, natural full campaigns, timed disconnects, remote event rendering and complete co-op Architect victories remain unverified (#110/#62). Native forced clicks and synthetic accept-action events are not physical mouse/controller passes. Long family/heir names do not enter these fixed dialogue localization templates; broader name/layout and input accessibility work remains in #57. Future fallback tests cover selectors/text rather than a hypothetical NPC's reward catalogue. This seeded audit samples actual rewards at each Ancient, rather than every possible native reward option or every party size.

## Reproduction

Build against an owned regular SDK. Use `scripts/run-balance-campaign.ps1 -AncientAuditChecks` with a fresh private lab/profile tag containing `selectors`, `dialogues`, `endings`, `cards`, `modifiers` or `saveboundaries`. Use `scripts/run-coop-audit.ps1 -Pair -AncientChecks` with `ancients56-mage`, `ancients56-ranger` or `ancients56-native` tags for peer ownership. `scripts/sts2-ancient-audit-evidence.py` validates completed private receipts and regenerates the issue-specific proof. Generic audit coverage and MODLOG remain ignored; game binaries, extracted assets and native saves are never committed. Launchers stop only their exact verified private client PIDs.

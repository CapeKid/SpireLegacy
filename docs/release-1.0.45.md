# 1.0.45 — Starter Defend names

Renamed all three Defend-tagged starter cards to make their existing synergy with cards such as Fasten clear:

- Knight: Guard → Guard Defend.
- Mage: Ward → Ward Defend.
- Ranger: Sidestep → Sidestep Defend.

Names use the same unparenthesized convention as Sword Strike, Spark Strike and Arrow Strike. Updated the card catalogue. Card IDs, Defend tags, costs, stats and gameplay are unchanged, including existing saves.

The owner authorized publication to public Workshop item **3816525393** (`SpireLegacy`) and private beta **3822395190** (`SpireLegacyBeta`). Both packages use the same DLL. GitHub main and Melty are not published by this release.

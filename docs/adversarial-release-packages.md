# Release package, installation and platform-path audit (#62)

Started from merged main `a3caaa3`. This audit changes contributor packaging and diagnostic tools, licensing and guides. It adds no native gameplay changes and performs no Workshop/Melty publication or personal-save/game-branch changes.

Confirmed fixes are #153, #154 and #155:

- The old packager included a fixture `.env` and obsolete artwork from dirty staging. Releases now come from a closed, verified input map and fresh staging; unknown prior files cannot enter any archive. The existing StS2 uploader marker is the sole retained local file and is excluded from portable archives.
- Promotion uses a recovery journal and output backups. Ordinary failures restore the previous release byte-for-byte; a process interruption leaves a plan that the next invocation rolls back before building. Recovery checks every target before mutation and refuses modified output or unsafe paths instead of deleting it. This is recoverable multi-path promotion, not an OS-wide atomic filesystem operation; readers must wait for the package command to finish.
- The caller must supply the expected release DLL SHA-256. Mismatching DLLs, unsafe versions, stale Melty mappings, wrong dependencies/branch restrictions/item markers and missing current release notes fail before promotion. A hash match establishes identity with the caller's reference; it does not by itself prove gameplay was tested. Final release checks must provide that reference.
- Archive validation stays enabled under Python `-O`. It rejects unknown/missing bytes, duplicate/case-colliding or unsafe paths, executable/symlink permissions, encryption, wrong sizes and CRC errors. Entries use fixed timestamps and regular-file `0644` permissions; game executables/launchers are not distributed.
- Packaging uses a tracked BaseLib MIT notice copied from the repository commit declared by NuGet 3.4.7. No ignored private license directory is needed. Bundled guides are UTF-8, close their local Markdown links, and point source/evidence links at the repository. The obsolete ignored coverage-manifest link was replaced by its tracked generator. Old current-version and Ancient/dialogue descriptions were corrected.
- A read-only install checker lists actual copies, versions, hashes, missing files/dependencies and actionable duplicate guidance. The native game gives an enabled local `mods` copy precedence over the same Workshop ID. Renaming a backup within a recursively scanned root still exposes it; move the unwanted copy outside both roots. Uninstall/update fixtures preserve separate family saves.

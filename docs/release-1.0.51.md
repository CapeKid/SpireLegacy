# 1.0.51 — Power icons

Eternal Bookmark now uses the native card-with-plus draw icon. The same misleading Strength sword fallback has been replaced for other custom powers: draw, Block, Energy, Retain, card recovery, Vigor, repeated attacks, triggered damage and class charges use corresponding artwork. Status-bar and tooltip icons share the same source. Gameplay, stable identities and saves are unchanged.

Release build and design preflight passed. All 51 generated powers loaded both icon sizes on regular v0.107.1 and public-beta v0.111.0. See power-icons-checks.json and power-icons.md. Publication to the public and private Workshop listings is authorized and pending delivery verification.

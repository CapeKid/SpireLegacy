# 1.0.38 — beta basic Strike names

Issue #186: Mage's basic Attack is now **Spark Strike** and Ranger's is **Arrow Strike**. Knight's **Sword Strike** already includes the word. All three now make their existing Strike relic eligibility clear from the name.

This is a display-name change. Saved model IDs, art files, costs, damage, upgrades, inherited traits and native Strike tags are unchanged. The native Strike Dummy relic uses the tag rather than the displayed name. The existing paid-card receipt now reports title, model ID and tags to make native verification reviewable.

Delivered only to the private **Spire Legacy — Beta** channel (mod ID `SpireLegacyBeta`, Workshop item **3822395190**). Public Workshop item **3816525393** and the public GitHub branch are not updated. The beta retains the Arcane Flow and Mage pool changes from 1.0.37.

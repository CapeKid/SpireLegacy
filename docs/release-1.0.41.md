# 1.0.41 — free Second Quiver reload

Second Quiver now costs **0 Energy** (down from 1), returning **up to 2 discarded Attacks** to hand (**3 upgraded**), then **Exhausting**. Removing the cost leaves Energy available to play the recovered Attacks and build Hunter Rhythm sequences. The recovery limits and optional selection are unchanged. Meditate remains unchanged.

This is a beta balance adjustment following feedback on 1.0.40. Saved IDs, artwork, rarity, pool membership and recovery behavior are unchanged. Physical Steam Deck selection and full-climb balance still need playtesting.

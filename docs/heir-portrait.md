# Heir character-selection portrait

The original opaque portrait is a 1024 × 1536 imagegen illustration by CapeKid under the repository's MIT terms. It uses a close-cropped silver helmet, small crown crest, green scarf and ochre background. Native TextureRects scale it into the existing 100 × 154 picker tile.

The current portrait replaced a transparent square cutout that left empty space in the vertical tile. Private game-art references informed style and framing; reference files are not distributed. Original generation/edit records have been removed from the current tree. Current `ui_art` art directions are descriptive specifications, not rewritten historical prompts. Asset bytes and hashes are unchanged.
